# AIPM reusable minimum record

From AIPM Framework v1.0. These are logical information requirements, not a requirement for six tools; one shared document is often enough. Mark unknowns rather than filling them with invented facts, and label unconfirmed owners as *proposed*.

| Field | Produced by skill |
|---|---|
| Outcome and beneficiary: | aipm-true-north |
| Measure, baseline source, target, and observation window: | aipm-true-north |
| Accountable outcome owner: | aipm-true-north |
| Assumption and disconfirming evidence: | aipm-break-the-mold |
| Next delivery increment or bounded experiment: | aipm-break-the-mold |
| Evidence references, dates, and limitations: | aipm-evidence-brief |
| Risk, issue, blocker, and dependency readiness: | aipm-dependency-readiness |
| Time, effort, cost, and quality boundaries: | aipm-break-the-mold / aipm-decision-brief |
| Decision owner, options, required date, and recommendation: | aipm-decision-brief |
| Observed result and total effort: | aipm-benefits-adoption |
| Continue, pivot, stop, or explicitly inconclusive: | aipm-applied-learning |
| Applied lesson, action owner, and review date: | aipm-applied-learning |
